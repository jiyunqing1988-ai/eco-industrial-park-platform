# 贡献说明

感谢参与生态工业园区评价与诊断平台的维护。

## 提交问题

请在 GitHub Issue 中说明发生问题的页面、操作步骤、预期结果和实际结果。计算问题还应说明指标 ID、输入数值、单位、属性选择和期望计算过程。只提交演示或脱敏数据，不上传真实园区的敏感数据、访客 Cookie 或访问密钥。

## 开发与验证

1. Fork 仓库并创建功能分支。
2. 使用 Node.js 22 或更高版本执行 `npm ci`。
3. 修改后执行 `npm test` 与 `npm run build`。
4. 涉及方案 API 时，用自己的 Netlify 站点验证保存、读取、删除和访客隔离。
5. 提交 Pull Request，说明问题、改动、验证结果和已知限制。

## 评价规则变更

请提供规则名称、发布机构、版本、适用范围及可访问出处；明确公式、单位、阈值、比较运算符和并列候选指标的汇总方式。添加阈值相等、阈值两侧以及相关区域/行业属性的测试。不要把未验证的行业假设写成官方要求。

## 命名和范围

新产出的文档和测试文件使用 `YYYYMMDDHHmm—名称` 时间前缀；`README.md` 与 `LICENSE` 保留标准名。框架约定的现有入口与配置文件在原位修改。保持改动聚焦，不提交 `.env`、`.netlify/`、`.playwright-cli/`、本机路径、运行日志、构建产物或私有方案。

提交贡献即表示你有权按本仓库 MIT 许可证提供该贡献。第三方代码需保留适用的版权和许可声明。
